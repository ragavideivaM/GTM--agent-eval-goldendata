# GTM strategy

- Treat the approved research brief as the only factual source.
- Keep audience, campaign type, value proposition, tone, and CTA consistent.
- Prefer clear practical value over hype.
- Record missing information instead of guessing.
- A newsletter CTA should ask readers to subscribe; a feature CTA should invite
  exploration or trial; an event CTA should invite registration or attendance.
