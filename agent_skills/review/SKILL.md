# Grounded review

- Check every factual statement against its evidence IDs.
- Check consistency across LinkedIn, email, blog, and ads.
- Check tone alignment, clarity, channel fit, and CTA quality.
- Remove or rewrite unsupported claims instead of inventing support.
- Apply human feedback only when it remains compatible with the approved brief.
- Final publishing still requires explicit human approval.
